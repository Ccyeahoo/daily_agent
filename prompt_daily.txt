【第 1 步：抓取数据】
运行：scripts\fetch_rank.py
    <python> scripts\fetch_rank.py --print-top 10

该脚本已经写好并验证可用，接口为
https://api.bilibili.com/x/web-interface/ranking/v2?rid=0&type=all
它已经处理了两个关键点，你不需要重写：
  1. 请求必须带 User-Agent 和 Referer: https://www.bilibili.com/v/popular/rank/all 请求头；
  2. 直接请求接口会被风控拦截，返回 HTTP 200 但 body 是 {"code":-352}。
     必须先请求一次 https://www.bilibili.com/ 种下 buvid3 cookie，再请求接口才会返回 code:0。
如果脚本失败，请阅读报错后修复它，不要把 -352 当成网络故障反复重试。

注意：本机 pip 无法联网（pip install matplotlib 会报
"No matching distribution found"），**不要尝试 pip 安装任何包**。所有脚本只用标准库。

原始 JSON 会保存到 data\raw\<日期>.json（约 250 KB，含 100 条）。请**分块读取**，
不要一次性把整个文件塞进上下文：例如先用 python 读出前 10 条的
bvid / title / tname / stat.view，再单独统计分区。

【第 2 步：生成图表】
运行：scripts\make_chart.py
    <python> scripts\make_chart.py --all --raw data\raw\<日期>.json --outdir daily_out\<日期>
一次产出 5 张 PNG，文件名固定且只能是 ASCII——邮件正文用文件名当 cid 引用图片，
中文名会被编码成 =?utf-8?b?...?=，客户端不解码 Content-ID，必定裂图：

    daily_top10.png     Top 10 播放量横向柱状图
    chart_donut.png     分区播放量环形图（播放量前 7 的分区 + 「其他」）
    chart_scatter.png   播放量 × 点赞率散点图（x 轴 log10，红点为离群点）
    chart_hist.png      时长分布直方图（6 档）
    chart_hour.png      发布时间分布（按 CST 小时，左轴条数 / 右轴平均播放量）

它内部用 PowerShell + System.Drawing 绘制（matplotlib 装不了）。运行后逐个确认
5 个文件都存在且大于 0 字节；单张小于约 5KB 基本就是空白画布。
只想重画某一张时用 --kind（hbar/donut/scatter/histogram/column）替代 --all。

【第 3 步：写日报】
输出到 daily_out\<日期>\daily_brief.md，必须包含以下内容：
  1. 数据截止日（即抓取当天日期）
  2. Top 10 视频清单，每条要有：名次、标题、BV号、UP主、分区、播放量
  3. 全部 100 条的总播放量
  4. 「最高播放量分区分析」——按分区聚合播放量，指出哪个分区最高、占总量多少、有几个视频入榜
  5. 「时长结构」——各时长档的视频条数，指出集中在哪一档
  6. 「发布时间规律」——发布小时的高峰时段，以及完全没有新视频发布的时段
  7. 「点赞率异常点」——点名至少 2 条「高播放低点赞率」和 1 条「低播放高点赞率」
  8. 一段约 100 字的数据说明

图表要内嵌进邮件正文，所以必须在 md 里用图片语法引用这 5 张图，并且
**分别放在最相关的小节标题下，不要堆在文末**：

    ![Top10 播放量](daily_top10.png)
    ![分区播放量分布](chart_donut.png)
    ![播放量 × 点赞率](chart_scatter.png)
    ![时长分布](chart_hist.png)
    ![发布时间分布](chart_hour.png)

写完 md 后必须跑一次 build_report.py 生成 HTML 正文：

    <python> scripts\build_report.py --md daily_out\<日期>\daily_brief.md \
        --out daily_out\<日期>\daily_brief.html --check-dir daily_out\<日期>

它把 ![](x.png) 改写成 cid:x，并校验正文引用的每张图都真实存在。它报错就说明图
没产出或文件名写错了，回第 2 步修，不要绕过这道校验。

写 Markdown 表格时注意：B站标题里含 `|`、`《》`、emoji 等字符，会把表格撑坏，
请先转义或替换掉标题中的 `|`。

【第 4 步：发邮件】
按仓库根目录的 SKILL.md 的说明，用 scripts\send_mail.py 发送。命令形如：

    <python> scripts\send_mail.py --subject "B站排行榜日报 <日期>" \
        --body-file daily_out\<日期>\daily_brief.md \
        --html      daily_out\<日期>\daily_brief.html \
        --inline    daily_out\<日期>\daily_top10.png \
        --inline    daily_out\<日期>\chart_donut.png \
        --inline    daily_out\<日期>\chart_scatter.png \
        --inline    daily_out\<日期>\chart_hist.png \
        --inline    daily_out\<日期>\chart_hour.png \
        --attach    daily_out\<日期>\daily_brief.md \
        --attach    daily_out\<日期>\daily_top10.png

要点：
  - 收件人从 scripts\smtp.conf 里的 to 字段读，命令行**不要**写 --to；
  - --inline 把 PNG 以 Content-ID 内嵌进 HTML 正文，手机上打开邮件就能看到图，
    不必下载附件。cid 由文件名自动推导，必须与 HTML 里的 cid:xxx 完全对应，
    而且必须与 --html 同时出现，否则脚本直接报错；
  - 附件只挂 .md 和 daily_top10.png 作兜底就够——5 张图已经内嵌在正文里，
    再全量 --attach 会让邮件体积翻倍。

如果 scripts\smtp.conf 不存在，说明发件人和授权码尚未配置。这种情况下：
  - 不要伪造任何邮箱、授权码或"发送成功"的结论；
  - 把**你实际执行的那条完整命令行**和**脚本返回的真实报错**原样记进
    daily_out\<日期>\mail_status.txt；
  - 然后继续，把这一情况写进最终汇报。
